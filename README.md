# ترادي ميرا | Tradi Mira — متجر إلكتروني

موقع متجر احترافي باللغة العربية (RTL) للملابس والإكسسوارات الأمازيغية التقليدية.
Professional Arabic (right-to-left) online store for traditional Amazigh clothing, accessories and handmade crafts.

## ✨ المميزات / Features

- تصميم عربي كامل من اليمين لليسار (RTL) وخطوط عربية أنيقة
- متجاوب مع الجوال والحاسوب (Responsive)
- عرض المنتجات حسب التصنيفات مع فلترة
- سلة مشتريات محفوظة تلقائياً (localStorage)
- **إتمام الطلب عبر واتساب** — يرسل تفاصيل الطلب مباشرة إلى رقمك
- زر واتساب عائم + روابط إنستغرام
- بدون أي مكتبات خارجية — HTML/CSS/JS فقط، سريع وسهل الاستضافة

## 📁 الملفات / Structure

```
index.html          الصفحة الرئيسية
css/style.css        التصميم
js/products.js       بيانات المنتجات والتصنيفات  ← عدّل هنا منتجاتك
js/main.js           منطق الموقع (السلة، الفلترة، واتساب)
assets/logo.svg      الشعار
assets/images/       ضعي صور المنتجات هنا
```

## 🛠️ كيفية التعديل / Customize

### 1. المنتجات والأسعار
افتحي `js/products.js` وعدّلي القائمة. مثال منتج:

```js
{ id: 17, name: "اسم المنتج", cat: "kaftan", price: 900, old: 1100,
  tag: "جديد", img: "assets/images/photo.jpg", desc: "الوصف" }
```

- `cat`: التصنيف (`kaftan` / `accessoires` / `khotoba` / `tissus`)
- `price`: السعر بالدرهم — `old`: السعر قبل التخفيض (اختياري)
- `tag`: شارة مثل "جديد" أو "تخفيض" (اختياري)
- `img`: مسار الصورة. اتركيه `""` لعرض قالب ملوّن بدل الصورة.

### 2. أرقام التواصل
- **رقم واتساب للطلبات**: غيّري `WHATSAPP_NUMBER` في أعلى `js/main.js`
- باقي الأرقام والروابط: في `index.html` (قسم "تواصل معنا" والفوتر)

### 3. الشعار
استبدلي `assets/logo.svg` بشعارك (يمكن استخدام PNG/JPG مع تحديث المسار في `index.html`).

## 🚀 النشر / Deploy

الموقع ثابت (static)، يمكن استضافته مجاناً على أي من:

- **GitHub Pages**: Settings → Pages → اختاري الفرع → احفظي
- **Netlify** أو **Vercel**: اسحبي المجلد أو اربطيه بالمستودع
- أي استضافة عادية: ارفعي الملفات كما هي

### تجربة محلية
افتحي `index.html` مباشرة في المتصفح، أو:

```bash
python3 -m http.server 8000
# ثم افتحي http://localhost:8000
```
